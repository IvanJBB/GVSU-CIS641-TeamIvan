# CIS 641 Term Project: Platformer Hopper

## Project Overview

Platformer Hopper is a 2D platformer game being developed in Unity. This project is specifically being done for Grand Valley State University's CIS 641 Systems Analysis and Design.

This game/project will include... 
\- A functional main menu and pause menu
\- Player movement (directional inputs & jumping mechanics) 
\- Goal completion screens

And more! 
This project is still a work in progress, and things are subject to change.
